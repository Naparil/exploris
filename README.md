# 조작키

__방향키__ : 목적지 설정

__z / x__ : 회전 (시계 / 반시계 방향)

__스페이스바__ : 블록 발사

__c__ : 폭탄

# 게임 방법

제한시간 내에 블록의 목적지를 정해 쏩니다.

한 줄 당 10칸에 블록이 쌓이면 줄이 사라지고 점수를 얻습니다.

5줄을 없앨 때 마다 레벨이 1씩 오릅니다.
